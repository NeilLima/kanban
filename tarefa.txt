# KANBAN PRO - Sistema Profissional de Gerenciamento de Projetos

## Objetivo

Desenvolver um sistema web completo de gerenciamento de projetos no estilo SaaS, inspirado em Linear, Jira, ClickUp, Monday.com, Asana e Notion, porém com identidade visual própria.

O sistema deve transmitir a sensação de um software comercial premium, desenvolvido por uma empresa de tecnologia moderna.

Utilizar:

- Next.js 15 (App Router)
- React 19
- TypeScript
- React-Bootstrap
- Bootstrap Icons
- Prisma ORM
- PostgreSQL
- pgAdmin
- React Hook Form
- Zod
- Axios
- Framer Motion

Toda a aplicação deverá ser componentizada, reutilizável, organizada e preparada para crescimento.

------------------------------------------------------------

IDENTIDADE VISUAL

O sistema deverá possuir aparência moderna, elegante e minimalista.

Inspirado em:

• Linear
• Atlassian
• Jira
• ClickUp
• Vercel

Evitar excesso de cores.

Evitar gradientes exagerados.

Utilizar bastante espaço em branco (ou espaço negativo no tema escuro).

Todos os componentes deverão possuir bordas arredondadas.

Todos os cartões deverão possuir sombras suaves.

Todas as animações deverão ser discretas.

EXPERIÊNCIA DO USUÁRIO

A interface deverá transmitir imediatamente a sensação de um software premium utilizado por empresas de tecnologia.

A navegação deve ser extremamente intuitiva, com foco em produtividade, rapidez e organização.

Os componentes devem seguir um padrão visual consistente, utilizando React-Bootstrap como base, mas personalizados para criar uma identidade própria. Os elementos devem possuir espaçamentos generosos, tipografia moderna, animações discretas, excelente contraste e responsividade completa.

O resultado final não deve parecer um clone do Trello ou Jira, mas sim um produto original, sofisticado, elegante e pronto para uso em ambiente corporativo, digno de compor um portfólio profissional.
